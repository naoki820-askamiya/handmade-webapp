# Webデザイン入門編

## エンジニアがデザインを知ったほうがいい理由

- クライアントやデザイナーとの認識の齟齬をなくす
    - 専門用語など
    - それらを減らせば作業効率が上がる
- 業務でのデザイナーへの依存度が変わる
    - デザインよりユーサビリディ優先のプロダクトとかの場合にデザイナーなしでできる
    - 単に自分の市場価値を上げるため
    

### 余白，文字，色を意識するだけでマシなデザインができる

---

## デザインを決める前にコンセプトやターゲットを意識

子供や若年層がターゲットの時は自由な感じのデザイン　色を多用

信頼性のあるイメージはネイビーや白を使う　明朝体を使う

高級感がコンセプトの時は余白をめっちゃ使う　セリフ体　明朝体を使う

情報量の多さをアピールしたいとき　あえて段組する　余白を狭くする

ぎっしり詰まっているから一度にたくさんの情報が入ってくる

## 色の基礎知識について

## RGB CMYK

red green blue 

作るデザインの用途によって使い分ける　webはRGBで，チラシは後者が多い

### 色の3属性について

- 色相
    - 近似色　捕食
- 明度　明るいかどうか
- 彩度　原色に近いかどうか

## キーカラー

一番使っていきたい色

それを基準に類似色やアクセントカラーを使う

基本的に，キーカラーをベースに

- 色相だけずらす
- 彩度だけずらす
- 明度だけずらす

## トーン

各色で彩度や明度の違いによって印象が浅いや暗い，鈍いのように決まっていて，色が違って印象が同じというものを選んでいくといい
